4. Mandatory Constraint Categories
5. Integration & Legacy Constraints
6. Acknowledged Architectural Risks
7. Trade-Off Boundary Declaration
8. Change Control Clause
9. Disclaimer

THIS ORDER IS IMMUTABLE.

ECP CONTENT GENERATION (CONFIGURABLE)

Each ECP section must be built using:

- A SECTION DEFINITION object:
  {
    sectionId: string,
    title: string,
    description?: string,
    source: "ADS" | "GRAMMAR" | "STATIC_TEXT",
    placeholderPolicy: "REQUIRED" | "OPTIONAL"

- Section definitions must be loaded from configuration,
  not embedded in UI JSX or components.

This ensures future evolution without refactoring.
